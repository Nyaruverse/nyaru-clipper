# 逐条字幕编辑

更新日期：2026-10-16。Web 与 macOS Companion 共用本功能。已按用户授权在本机安装 0.1.8 build16，历史任务和数据保留；开发分支发布信息见[当前交接](project-handoff.zh-CN.md)。App 为本地签名，未公证。

## 使用

1. 打开一个已完成任务，点击主工作区中的字幕，或打开顶部「字幕样式」。右侧的逐条编辑器分为「内容／位置／样式／时间」。点击字幕会选择并跳转；复选框用于多选，查找支持筛选，每页显示 20 条。
2. 「内容」分别修改本条原文、译文。「局部文字强调」先选择设置对象，再在只读选区框内选择文字，应用颜色和加粗。修改正文会清除对应语言的旧强调，避免范围错位。
3. 「位置」支持 X/Y 数值、九宫格锚点、拖动画面锚点、方向键微调、居中和恢复自动位置。方向键每次移动 **1 个输出视频像素**，Shift 为 10 像素。拖动时 Shift 锁定主要轴，Alt 暂时跳过吸附。参考线和安全区可以关闭。
4. 「样式」支持字体、粗体、斜体、下划线、字号、文字透明度、字距、行高、换行宽度、旋转、横纵缩放、描边、阴影、底板颜色／透明度／内边距和隐藏。字体输入可选择服务所在机器的字体；缺失字体会警告，系统无法枚举时明确提示未知。字体家族可用不等于每个字符都有字形。
5. 「时间」可编辑起止秒数、按源视频帧率提前／延后一帧、批量平移、在播放头拆分和合并相邻字幕。拆分按时间比例分配文字，需人工复核断句；合并保留第一条的独立样式。循环播放需打开选项并点击视频播放。
6. 位置和样式应用于全部所选字幕；原文／译文可分别操作，也可开启联动。可复制样式、仅粘贴位置、应用当前全局模板或恢复继承。全局样式与模板位于抽屉底部；本条一旦使用独立样式，该语言整套样式独立，恢复继承后才继续跟随全局修改。

X/Y 是源视频有效画面的坐标，不包括播放器黑边。字号、边距等既有样式单位仍按 1080 高度缩放。明确指定 X/Y 后不再自动移动字幕避让；重叠请通过预览核对。

## 保存、恢复与数据保护

修改后约 650 毫秒自动保存；等待「已保存」再导出。撤销／重做最多保留 100 次会话修改。切换任务时，当前页面内各任务的草稿保留；正常重启恢复的是已成功保存的版本。存在未保存修改时，浏览器尝试提示离开；不要依赖这个提示替代保存状态。

编辑稿单独写入任务目录 `subtitle-document.json`，使用版本号防止另一个窗口覆盖。时间无效、坐标越界、源字幕变化或版本冲突时拒绝保存；本地草稿和旧服务器版本保留。出错时可展开「保留当前编辑稿（JSON，可复制）」手工备份，再核对或选择「从当前源字幕重新开始」。源指纹变化时重建会先保留旧编辑稿备份。

本功能不覆盖原始 SRT、识别／翻译结果、源媒体或旧导出。原有 SRT／TXT 下载仍是原始结果。修改仅用于新生成的样式导出。不得通过手动改原任务文件来绕过校验；服务运行期间也不得另启一个服务写同一任务根目录。

## 预览与导出

精确预览由与导出相同的 ASS／libass 渲染，输出透明图片叠加在视频有效画面上。切换字幕或修改内容时显示渲染状态，不继续展示已失效的字幕图片。需要 FFmpeg 的 libass 支持；本机编辑不会调用识别、翻译或付费服务。

- **ASS**：保留编辑文字、逐条样式、位置及时间；可以选择完整视频或切片。
- **烧录 MP4**：保留上述效果，目前仅支持已完成切片。视频有损编码，因此与透明预览不要求逐像素相等。
- **ArcTime ZIP**：包含编辑后的 ASS／SRT、编辑稿 JSON、样式及原有交接资料。SRT 仅承载文字和时间；高级视觉效果依赖 ASS 或烧录。导入第三方软件后仍需检查其字体和样式解释。

切片导出使用源视频的绝对时间选取交集，截断边界并换算到切片零点。ASS 时间精度为百分之一秒，预览按相同边界判断；时间输入的更多小数不会提高 ASS 格式精度。

## 本轮验证与限制

两个工作树各通过 Companion 前端 **65 项测试**和 TypeScript／Vite 构建，覆盖重叠，不能相加。后端字幕、模板、API、渲染、GUI、翻译与 macOS 回归 **160 项通过**，另有上游 TestClient 弃用提示。Web 工作树另独立通过其中的 50 项编辑稿／字体测试。多行顶部、底部和居中的位置回归覆盖自动锚点转为明确坐标，以及另一语言位置保持不变。

合成短视频 HTTP 流程覆盖编辑、持久化、透明预览、ASS 和烧录。竖屏与奇数尺寸的预览合成相对直接 ASS 渲染最大通道差不超过 3/255。最终 build16 冻结后端与原生 WKWebView 实测覆盖多行底部、居中、顶部双语排版、分别微调原文／译文及联动数值定位；预览／烧录 RMSE 分别为 1.355、1.507、1.422/255，包含有损编码差异。像素边界确认横向移动 1 像素时纵向及另一语言位置保持不变。邻句、原始文件及旧导出哈希不变。早期验收还覆盖源变化、版本冲突、无效时间拒绝，以及缺失字体警告和恢复字体。

本地详细证据在 macOS 工作树 `.omo/evidence/subtitle-editor-2026-10-16/`，含 `acceptance.md`、`integration-backend.log`、`browser-reviewed-visual-matrix.json`、`native-candidate-{bottom,center,top}-verification.json`、`native-report.md` 和 `position-delta-review.md`。早期拒绝报告 `final-gate.md` 保留为历史；其 G1 问题修复已通过新一轮代码复核和打包实测。证据与合成媒体不作为产品源码提交。
