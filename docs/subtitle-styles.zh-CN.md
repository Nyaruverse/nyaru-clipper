# 字幕样式、模板与 ArcTime 精修

本地 Companion 的「字幕样式与模板」面板支持原文和译文分别设置字体、字号、文字颜色、描边、背景不透明度、上下位置和边距。样式用于播放器预览、ASS 下载和切片字幕烧录。两种语言共享已有时间轴，不需要重新识别或翻译。

新增逐条编辑、精确 X/Y 定位、高级样式、自动保存和 libass 精确预览，见[逐条字幕编辑](subtitle-editor.zh-CN.md)。全局默认与模板位于抽屉底部；原始下载入口仍保留原始结果。

## 使用

内置「猫雷 Nyaru｜薄荷电波·中日双语」为新安装的默认样式：日文圆体淡紫白 44、中文薄荷青绿 64 加粗、深紫描边，按 1080 高画布缩放。新建实时录播默认选中此模板，可改为不自动套用。原有「双语基础」「单语白字描边」仍可选择；内置样式只读，修改后另存为新模板。已有用户默认配置正常保留；本机本次按明确要求通过设置接口改为猫雷默认，旧值包含在完整备份中。

1. 选择已完成的任务，在预览中选择完整视频或一个切片，再选择原文／中日双语。
2. 打开顶部「字幕样式」，按逐条编辑指南修改字幕；抽屉底部「全局默认样式与模板」用于调整默认参数或应用模板。「样式字幕预览」控制叠加显示；「含字幕全屏」包括字幕，画面内有退出按钮。
3. 点击「导出 ASS」「烧录切片 MP4」或「导出 ArcTime ZIP」。烧录只支持切片，需要当前 FFmpeg 提供 libass；能力不足时按钮和说明会明确提示。
4. 导出完成后使用对应下载入口。macOS App 使用系统保存面板；浏览器使用文件下载。每个新输出记录提交时的样式、语种和范围。

字号和边距按 1080 高参考画布填写；逐条 X/Y 则使用源视频像素。编辑稿的精确预览、ASS 和烧录共用 libass 渲染。自动双语位置保留间隔；指定坐标后不再自动避让，请核对重叠。无效坐标和时间会被拒绝。字体必须在本机和精修机器上可用，第三方 ASS 播放器与 ArcTime 可能采用不同的字体或样式解释；没有编辑稿的旧预览仍采用浏览器排版。

## 两类模板

### 从 ArcTime ASS 读取并用于实时切片

1. 在 ArcTime 导出 UTF-8 或 UTF-16 的 ASS，并保留 `PlayResX/PlayResY` 画面分辨率。打开「字幕样式 → 全局默认样式与模板 → 导入 ArcTime ASS 样式」。文件上限 1 MiB、最多 256 个样式。
2. 从读取到的样式列表中分别选择原文和译文样式，填写名称，点击「保存 ASS 为样式模板」。只有一个样式时，两种语言可以共用；保存后的模板支持已有 JSON 导出、复制和重命名。
3. 新建任务选择「实时录播」，填写直播间号，在「实时切片字幕模板」中选择刚保存的模板。开始时保存样式快照；后续改名、修改或删除模板不会改变该任务。恢复处理继续使用任务快照。
4. 每个已完成切片自动新增 ASS 与烧录 MP4，出现在「导出 → 样式字幕导出」；双语可用时使用双语样式，翻译未完成时先提供原文版本。原 MP4/SRT 和历史导出保留。自动样式失败会提示并保留录制，结束后可用「恢复处理」重试。

支持字体、字号、BGR 颜色与文字透明度、粗斜体／下划线、描边、阴影、九宫格对齐、左右／垂直边距、字距、旋转和缩放。字号、描边和边距按原 ASS 分辨率换算至 1080 高参考画布，再按视频尺寸渲染。仅导入样式表，正文、逐句 `pos/move`、覆盖标签、淡入淡出、动画和卡拉 OK 不导入；删除线、独立描边／阴影透明度及不透明底板会提示未支持或近似。参数超出支持范围会报错，不静默截断。

字体需安装在本机；预览及渲染不下载字体。直播录制中的播放器使用浏览器排版，精确样式以 ASS／烧录视频为准；任务完成后的编辑稿可用 libass 精确预览。烧录与识别／翻译串行消费录制块，会增加积压；无 libass 时不能启动带自动样式的直播，可取消模板继续录制。

**字幕样式模板**支持另存、复制、重命名、确认删除及 JSON 导入／导出。内置「双语基础」「单语白字描边」只读，请另存副本。复制成功后会选中副本，继续修改和下载针对副本。保存为默认后重启仍生效；恢复默认只修改当前草稿。名称冲突、损坏 JSON、非法参数均显示错误。

**ArcTime 工程模板**通过上传 `.atpj` 登记，只复制原文件，最多 16 MiB。可选择、下载和删除登记副本，也可关联到一个字幕样式模板。被样式模板引用时，先解除关联再删除工程模板。Nyaru 不解析或改写其中的媒体、文字和特效；它与 Nyaru 的预览样式分别保存。

模板目录为任务根目录下的 `templates/`，独立于 DeepSeek Key 配置。macOS App 位于 `~/Library/Application Support/Nyaru Clipper/runs/templates/`。样式文件和默认设置采用原子写入和受限权限。

## ArcTime 精修

精修 ZIP 包含同名视频、ASS、原文 SRT、已有双语 SRT、`style.json`、`manifest.json` 和说明；选定工程模板时包含 `template.atpj`。视频没有新增烧录字幕，切片字幕从零计时；完整视频字幕保持原时间轴。包内生成文件使用相对路径，校验和可检查传输完整性。

1. 解压到新的工作目录，在 ArcTime Pro 导入 `source.mp4` 或 `clip.mp4`。
2. 使用「导入 ASS 字幕」，选择同名 ASS，并导入样式。文字和时间轴可继续编辑。
3. 如需复用工程模板，使用 ArcTime 的「从其它工程文件导入样式」，选择 `template.atpj`。检查重名样式覆盖选项及字幕分组；旧工程可能使用不同分辨率，覆盖同名样式会替换本次换算后的字号。要保留 Nyaru 外观，可先导入工程样式，再导入 ASS 样式。
4. 调整文字、时间、字体和排列，另存一个新工程。ArcTime 可能重排字幕层并自动添加淡入淡出，请播放检查双语和背景效果。

ArcTime 保存可能生成与媒体同名的 ASS，请在解压副本里精修，保留原交接包。原生 ATPJ 保留其原始字节，可能自带旧媒体路径和 ArcTime 用户标记；分享前检查原模板内容。`style.json` 记录 Nyaru 参数；需要在 Nyaru 复用的 JSON 请通过样式模板下载入口导出。

macOS 的「打开 ArcTime」只启动软件；「打开导出文件夹」打开任务目录。精修包提供可编辑文件交接，不自动生成填好新内容的原生 ATPJ，也不调用 ArcTime 云转写。

## 文件与恢复

新输出使用 `styled-<标识>.ass/.mp4/.zip`，原视频、SRT、识别和翻译缓存保持原样。不同样式或新的渲染版本生成不同文件；已成功的相同导出会校验后复用。导出期间一次只处理一个任务，提交时冻结样式。

失败或中断后重新导出即可重试。可校验的已完成文件能恢复到下载列表；已有文件或恢复记录不匹配时保留原文件并报错。下载会检查输出校验和。旧记录没有样式字段时显示「样式信息未记录」，不会冒用当前编辑样式。
