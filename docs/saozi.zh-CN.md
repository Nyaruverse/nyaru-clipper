# 臊子：连续语义切片

臊子将视频连续切为约 1–2 分钟，使用已保存的 DeepSeek Key 和模型分析字幕段落。视频、识别和编码在本机完成；发送给 DeepSeek 的是字幕文字、候选切点和时间信息，会使用 API 额度。

## 使用

在「新建任务」选择视频来源；下载视频和本地视频再到「切片方式」选择「臊子」：

- **下载视频**：输入已结束视频的 BV 号，无需完整链接。
- **本地视频**：选择录像文件。任务保留一份独立副本，原文件不改动；也可选择指定时间段或高光模式。
- **实时录播**：输入正在直播的 Bilibili 直播间号，如 `12345`，无需完整链接。固定使用实时臊子；当前不支持其他平台实时输入。

选择语种并开始。实时模式边录边识别；生成的切片可以立即预览和下载。「停止直播并导出剩余内容」会先停止录制，再处理积压与尾段。直接关闭 App 会中断处理；重新打开后用「恢复处理」处理已保存录制，不会自动重新连接直播。

通常切片为60–120秒；不足一分钟的原视频或尾段仍完整保留。DeepSeek优先选择句末或话题收束处，模型只选择本地提供的候选切点。长句没有合适边界时会按120秒上限切分并标注边界受限；静音按时长切分并明确标注。不能保证每片都绝对语义完整，识别错误也会影响判断。

切片主题与理由显示在导出结果中。每片保留MP4和从零计时的原文SRT，并自动生成「双语 SRT」（clip-NNN.ja-zh.srt）：日语原文配中文译文，中文原文配日语译文。默认预览可用的双语字幕。实时任务在录制期间逐片补齐双语，翻译可能稍晚于视频发布；链接仅在字幕校验通过后出现。字幕样式、ASS、烧录与ArcTime交接仍可使用。

## 进度与失败

实时首片需要积累至少约140秒内容，再完成识别、API和编码。处理慢时保留录制并显示积压，不承诺首片在第120秒内出现。网络断开会有限重连，断流前后分别保留，界面明确标出无法恢复的缺失内容。

API超时、Key无效、余额不足或响应非法会报错，已识别字幕、已完成切点及切片保留，可恢复。恢复绑定原模型和检查点；修改默认模型不会重切已经发布的片段。不要手工改任务清单或覆盖已输出文件。

双语翻译失败不会中止原文录制或删除已有切片。任务结束后可点击「继续生成中日双语字幕」，CLI可用resume重试；已完成的翻译批次不会重复请求。极少数进程在全局双语字幕发布与检查点更新之间退出时，会保留文件并报校验错误，需要检查任务，避免覆盖手工修改。

## CLI

先用同一输出目录的GUI保存DeepSeek配置，再使用：

```bash
python scripts/local_companion.py run https://example.org/replay --saozi --output-dir data/local-runs
python scripts/local_companion.py run /absolute/video.mp4 --saozi --local --output-dir data/local-runs
python scripts/local_companion.py run https://live.bilibili.com/12345 --saozi --live --output-dir data/local-runs
python scripts/local_companion.py resume data/local-runs/TASK_ID
```

CLI实时模式用Ctrl+C停止录制并收束尾段。输出目录应由一个服务实例独占。Key只保存在私密配置中，不要把配置或原始录制提交到Git。
