# Creative Studio

The light workspace provides Daily mode, Template Design, and a unified Settings center, with mint accents for primary actions.

## Daily mode

Create a live, downloaded, or local-video task from the toolbar and select a work template. New tasks apply software defaults, then template defaults, then task overrides. A task keeps its creation-time template snapshot; later template edits do not rewrite existing tasks.

The timeline and full transcript stay below the video. Select a cue to edit its text, size, or position in the inspector. Advanced editing exposes timing, emphasis, and other typography controls. Cue documents autosave and surface pending/error states. The export panel offers ASS, subtitled clip MP4, and ArcTime ZIP. Original subtitle downloads retain the recognition output.

## Template Design

Switch modes with the top segmented control. Editable sample text uses the real ASS renderer, including when no task exists. The neutral canvas checks subtitle appearance and does not imply recorded footage.

Select a template, change its typography, streamer/work-series metadata and workflow defaults, then update or save a copy. Built-in templates require a copy. Custom templates carry revisions; stale drafts report a conflict. Design, Settings, and task subtitle drafts retain their own editing state.

## Settings

Open Settings from the toolbar or macOS Settings menu (Command-comma). Categories cover General, AI and Translation, Recognition and Processing, Subtitles and Templates, Files and Export, and Runtime.

The footer saves or cancels new-task defaults. AI connections, authorization and template operations retain their explicit save actions. Settings do not overwrite existing tasks, and leaving and returning retains an unsaved draft. Runtime capability and provider status come from the local service.

Switching modes and Settings preserves the current task, input draft and playback position. This UI change does not start recording or restore deleted tasks.
