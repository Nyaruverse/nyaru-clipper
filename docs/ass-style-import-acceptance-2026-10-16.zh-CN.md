# ASS 样式导入及实时套用验收

日期：2026-10-16。本页记录打包之前的 ASS 阶段验收；其后已整合到本机 build18，并纳入 Web／macOS 开发分支发布。当前状态见[交接文档](project-handoff.zh-CN.md)与[build18 验收](nyaru-default-build18-acceptance-2026-10-16.zh-CN.md)。

## 实现

- UTF-8/BOM 与 UTF-16 ASS 样式读取，1 MiB／256 样式限制，按 Format 字段解析，验证分辨率、颜色、字体及数值。支持 ASS BGR/透明度和按分辨率换算；不复制正文或执行覆盖标签。原文／译文由用户显式映射后保存为已有模板。
- 实时录播可选择保存模板，任务创建时固定快照及摘要。录制中逐段生成额外 ASS 和烧录视频；翻译可用后补齐双语版本，手动翻译重试亦触发补齐。改／删模板不影响现有任务，已完成输出校验后复用。
- 失败保留录制和原始片段，显示样式错误，结束后可恢复处理。首次打开已完成直播的编辑器继承快照；左右边距在 ASS、烧录和编辑锚点中一致。

## 证据

- 两个工作树各通过后端 227 项、前端 Companion 75 项和 TypeScript/Vite 生产构建；数量为同一测试集在两端执行，不能相加作为覆盖面。依赖原有一条 Starlette/httpx 弃用警告仍存在；LSP 未安装，Python 依据实际测试验证。
- Chrome + 真实本地 API：ASS 读取、双语映射、模板保存、新建直播选择、无效导入保留当前样式。390／1440／1920 宽度、light/dark 偏好共六张映射截图，另外保存选择及错误截图，无浏览器脚本错误、无页面横向溢出。应用保持现有纸色主题，dark 偏好不意味着新增暗色主题。
- 真实 FFmpeg/libass：160.512 秒合成录制块导出 3 段及 6 个样式产物，输入未结束前已发布首对 ASS／MP4。实际烧录帧显示导入的红字、黑描边和左上位置；首段视频 60.2 秒。恢复后输出标识不变，无重复编码。
- 本地证据位于 macOS 工作树 `.omo/evidence/ass-style-import-2026-10-16/`，包括 `browser-qa.json`、`media-smoke.json`、截图和隔离测试数据；不纳入 Git。

## 边界

本轮使用标准 ASS 合成样例、真实浏览器和 FFmpeg；ASR／切点为测试夹具，未连接真实直播或外部 AI，也没有用户实际 ArcTime ASS 样例的逐像素还原验收。正文内覆盖、动画、逐句定位及卡拉 OK 不导入；删除线、独立描边／阴影透明度和底板近似有显式提示。直播浏览器预览近似，精确结果以 ASS／烧录为准。烧录可能增加积压。

用户任务、模型、配置与安装目录未修改；工作使用既有两个开发工作树，主目录未编辑，master 未变。使用步骤见[字幕样式](subtitle-styles.zh-CN.md)。
