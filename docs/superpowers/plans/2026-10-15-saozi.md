# 臊子 Implementation Plan

**Goal:** 实现回放、本地录像、Bilibili 实时语义切片，并使用 40c0c9a8e93e 验证与更新 macOS App。

**Architecture:** 沿用 Companion 单任务管理、whisper.cpp、FFmpeg 与 DeepSeek 配置。共享语义选择器负责校验切点；实时录制把已关闭媒体块交给滚动处理器，保留恢复检查点。

**Tech Stack:** Python 3.11、现有 FastAPI/Pydantic/httpx、yt-dlp、FFmpeg、React/TypeScript、Vitest/pytest。

## Global Constraints

- 完整设计：`docs/superpowers/specs/2026-10-15-saozi-design.md`，已获用户确认。
- 普通片长 60–120 秒；短尾段保留；连续覆盖，不覆盖已有结果。
- 实时只支持 Bilibili；API 失败明确报告；原任务、模型、配置与失败证据保留。
- 不提交或推送；在现有 web/macOS 工作树修改，不重置用户文件。

## Task 1: 语义切点与检查点

Files: `backend/app/arctime/saozi.py`、`backend/tests/test_saozi.py`。

Interface: `SaoziSelector(key: SecretStr, model: str, client: httpx.Client | None = None)`；`choose(cues, start, duration, final=True)` 返回含 start/end/score/reasons/title 的切片 dict 或尚未积累足够内容时的 None；`plan(directory, cues, duration, progress=None)` 持久化完整连续选择。

- [ ] 测试连续覆盖、尾段、非法候选、长句、静音、网络错误和缓存恢复，观察缺失实现失败。
- [ ] 模型只返回候选 ID；本地时长与响应校验；检查点绑定字幕、模型与提示版本。
- [ ] 执行 `PYTHONPATH=backend ~/.cache/nyaru-clipper/companion-venv/bin/python -m pytest backend/tests/test_saozi.py -q`。

## Task 2: 录制与滚动处理

Files: `backend/app/arctime/live_capture.py`、`backend/app/arctime/saozi_live.py`、对应测试。

Interface: `LiveCapture(url, directory, stop)`；`chunks()` 持续产出已关闭 Path；`close()` 收束 FFmpeg。`run_live(directory, selector, adapter, stop, progress, url=None)` 创建／恢复 version 2 任务，逐片持久化 selection/completed_clips，停止后合并完整 source.mp4 与全局字幕。测试可注入可控录制实现，不把模拟站点当成 Bilibili 验收。

- [ ] 测试进行中的输出、停止尾段、断流、进程清理、恢复与非 Bilibili 拒绝，先失败。
- [ ] yt-dlp 解析流，FFmpeg 记录短块；只消费已关闭块；录制独立于识别／API。
- [ ] 用真实 FFmpeg 和 40c0c9 片段测试流式输出，记录输出时源仍运行的证据。
