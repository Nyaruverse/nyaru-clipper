# 创作工作台

工作台提供日常模式、模板设计模式和统一设置中心，采用浅色界面与薄荷色操作重点。

## 日常模式

从顶部新建任务，选择实时录播、下载视频或本地视频，再选工作模板。新任务按“软件默认 → 模板默认 → 本次调整”应用参数，任务保存创建时的模板快照。更新模板不会重写已有任务。

视频下方保留时间轴与完整字幕。点击字幕后，在右侧修改本条内容、字号和位置；需要时间、强调及更多排版时展开高级逐条编辑。字幕编辑稿自动保存，错误和未保存状态会显示在面板中。通过顶部导出选择 ASS、字幕 MP4 或 ArcTime ZIP；原始字幕下载保留识别结果。

## 模板设计

顶部滑块切换模板设计。此处的样例文字通过实际 ASS 渲染引擎生成，可以在没有任务时检查字体、描边、颜色和双语排列。预览使用中性画布，不代表真实录制画面。

选择模板后调整样式，填写主播或工作系列、处理与导出默认值，并更新模板或另存。内置模板须复制后保存；自定义模板带版本，过期草稿更新会报告冲突。模板设计草稿、设置中心草稿和当前任务字幕分别保存各自的编辑状态。

## 设置中心

使用顶部设置按钮或 macOS 的“设置…”菜单（⌘,）打开。分类为通用、AI 与翻译、识别与处理、字幕与模板、文件与导出、运行环境。

新任务默认值通过底部保存或取消更改。AI 连接、授权及模板管理保留各自明确的保存操作。设置不覆盖已有任务，离开设置再返回会保留未保存草稿。实际能力状态由本地服务返回；未配置 AI 或缺少组件时显示真实提示。

本版不启动录制或恢复历史任务。切换工作模式及进入设置会保留当前任务、输入草稿和播放器位置。
